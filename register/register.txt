명령어에 따라 레지스터 데이터를 전송하는 동작은 t3에서,
레지스터에 데이터를 저장하는 동작은 t5에서 동작된다.

각 제어신호의 설명은 instruction decoder에 있다.

총 8개의 레지스터이며, 내부 블록으로 동작한다.

temp_des,temp_src는 move와 HXHG명령어 동작에 사용된다.

alu로 전송되는 l/r operand_en의 경우 t3에서 연산이 동작되기에 동일한 시점에 전송할 경우
연산이 되지 않기 때문에 조합논리로 연결하였다.

rd_data와 rs_data는 data bus로 전송되며 data memory 쓰기 동작에 사용된다.

alu_result0와 alu_result1는 alu의 연산결과를 t5에 저장할 때 사용된다.

dbus_in_data는 data memory 읽기 데이터를 data bus를 통해 입력된다.

value는 LDIL,LDIH 명령어 동작에 사용된다.
