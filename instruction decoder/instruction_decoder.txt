state control에서 t2일때 명령어 decode,제어신호 생성

op_group[4:0] : opcode, 이것으로 명령어 종류를 크게분류
op_kind[N:0] : 세부 동작을 비트로 정의 , 다른 블록에는 이 신호가 전송됨
enable은 1비트로 설정해 각각 이름을 정의해야 함.

rd,rs,offset,value는 일단 변수를 정의해서 0을 저장하고, op group에
따라서 instruction비트에서 맞는 비트를 대입.

명령어가 비어있는 비트는 0으로 간주.

op_group으로 1차 정의, 내부에서 sop1,2로 op_kind정의, 세부 제어신호 생성

des_reg[3:0]
src_reg[3:0]


LD,ST명령어를 위해 data bus block과 연결.
이때 data bus block에 전달될 rs,rd는 register비트가 아니라, 실제 데이터/주소값
따라서 data bus blcok은 register block과 연결.

t2에서 생성된 제어신호가 다음 t2까지 저장되어야 다른 블록에 입력되어
동작한다. 따라서 제어신호를 2개 생성해서 t2마다 초기화되는 내부 제어신호,
clock마다 제어신호를 갱신하는 입력 제어신호를 각각 정의한다.
always 구문을 2개로 나누어 작성.
1. decoder 조합 출력
   - 항상 현재 instruction을 보고 계산됨
   - always @(*) 안에서 매번 기본값 0으로 시작
   - 명령어에 해당하는 신호만 1로 set

2. control register 저장 출력
   - T2 clock rising에서 decoder 조합 출력을 저장
   - T3~T5 동안 유지
   - 다음 명령어의 T2에서 새 값으로 덮어쓰기

sop코드가 빈칸으로 정의된 경우 0으로 간주한다.
