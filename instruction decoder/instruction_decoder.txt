instruction decoder에서는 t1에서 갱신된 16bit명령어를 입력받아 해석하고 t2에 제어신호를
출력한다.

각 flag들은 status register에서 조건분기를 검사하기 위해 입력받는다.

des_sec, src_reg는 명령어 해석에 사용되는 Rd,Rs의 번호이다. register에서는 이것을 입력받아
해당 레지스터의 데이터를 다른 블록들에 전송한다.

offset은 분기명령어의 pc+offset이다.

reg_value는 LDIL,LDIH의 value값이다.

alu_value는 Shift&rotate명령어의 value값이다.

n은 bit manipulate명령어에서 레지스터 번호 또는 플래그 번호를 의미한다.

특수 제어신호들이 별도로 필요한 경우, 그 명령어의 이름으로 제어신호가 명시되어 있다.

reg_dt_sel은 alu연산결과를 t5에서 레지스터에 저장해야 할 경우 set된다.

reg_wr_en은 t5에서 레지스터에 데이터를 저장해야 할 경우 set된다.

ldl_value_en은 LDIL의 전용신호이다. register에 연결된다.

ldH_value_en은 LDIH의 전용신호이다. register에 연결된다.

mem_rd_en은 data memory에 쓰기 동작인 모든 명령어에서 set된다.

mem_wr_en은 data memory에 읽기 동작인 모든 명령어에서 set된다.

dbus_access,dbus_addr_sel,dbus_data_sel의 상세한 설명은 data bus를 참고 바란다.

sp_sel은 pop/push 동작에 사용되며 stack pointer 해당 코드에서 이해가 가능하다.

sp_wr_en은 sp의 값을 변경하는 모든 명령어에서 set된다. sp_sel과 함께 사용된다.

operand_en은 alu연산에 필요한 데이터를 전송하는 동작이다.

sreg_wr_en은 flag갱신 가능신호이며 모든 alu연산 명령어에서 set된다.

sr_bit_en, sr_bit_sel, sr_bit_idx는 전부 CLR/SET SR에 사용된다.

exe_32는 MUL곱셈 명령어에서 32비트 결과값을 2개의 레지스터에 저장하도록 한다.

pc_wr_en은 t5에서 분기,ret등의 명령어를 수행할 때 pc값 변경에 사용된다.

clr,set은 각각 CLR/SET Rd 명령어이다.

t2에서 생성된 제어신호가 다음 t2까지 저장되어야 다른 블록에 입력되어
동작한다. 따라서 제어신호를 2개 생성해서 t2마다 초기화되는 내부 제어신호,
clock마다 제어신호를 갱신하는 입력 제어신호를 각각 정의한다.
always 구문을 2개로 나누어 작성.
1. decoder 조합 출력
   - 항상 현재 instruction을 보고 계산됨
   - always @(*) 안에서 매번 기본값 0으로 시작
   - 명령어에 해당하는 신호만 1로 set
   - 내부 제어신호는 뒤에 dec붙임.

2. control register 저장 출력
   - T2 clock rising에서 decoder 조합 출력을 저장
   - T3~T5 동안 유지
   - 다음 명령어의 T2에서 새 값으로 덮어쓰기

sop코드가 빈칸으로 정의된 경우 0으로 간주한다.
