sreg_wr_en이 instruction decoder에서 ALU연산으로 동작될시 set.
T5에서 연산결과에 대한 flag가 갱신됨.

T2 조건분기 검사에서 flag값이 instruction decoder에 입력.

ALU block에서 flag를 결정하고, SR block으로 넘겨서 저장하는 방식.
ALU block에서 서브 모듈을 정의하여 flag를 정의하는 방식.
carry와 overflow는 ALU내부에서 결정해서 flag 서브 모듈로 넘겨야 함.

조건분기검사는 instruction decoder에 연결하여 검사, assign문으로 할당된
신호들을 연결.

cf_out : alu carry bit 연산

sreg_wr_en : ALU 연산 결과를 갱신 허용신호

sr_bit_en : Bit manipulate명령어 실행시 set
sr_bit_sel : Bit manipulate명령어 실행시 0일때 CLR, 1일떄 SET
sr_bit_idx : Bit manipulate명령어 실행시, 8비트 flag bit 설정
