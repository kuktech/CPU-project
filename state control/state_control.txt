clock cycle마다 t1 t2 t3 t4 t5 타이밍 신호를 블록들의 동작에 맞게 전달한다.
Rotator로 구성 
clear/ResetB : Sequence counter <=000;
            Rotator <= 10000

t1 : 명령어 인출단계 , program counter,instruction register
t2 : instruction decoder,  제어신호 생성
t3 : ALU연산결과를 저장 , ALU,program counter
t4 : data memory접근할때 유효, 결과 저장 , stack point,data bus
mem(RD) <- RS , RD <- mem(RS)(RD접근은 t5에서, load buffer에 저장)
t5 : register저장
RD <- RD + RS에서 RD에 저장하는 단계

halt명령어의 경우 파이프라인 설계를 고려했을 때, decoder에서 halt제어신호가 set된후
t3에서 시스템이 종료되면 다른 명령어들이 동작을 다 마치기 못하기에, 반드시 t5에서 동작
되어야 한다. 

halt가 실행되면, case문의 default가 무한히 반복되어 타이밍 제어신호가 생성되지 않는다.
초기화가 되기 전까지 유지된다.
